## 介绍

- 基于 Vue3、TypeScript、Element Plus、Vue Router、Pinia、Axios、i18n、Vite 等开发的后台管理前端。
- 可对接后端工程：`icejz-boot`（单体）和 `icejz-cloud`（微服务）。

## 安装

注意：需使用 Node.js 长期维护版本（如 22.x）。

```bash
# 进入项目
cd icejz-admin

# 安装依赖
npm install

# 运行项目
npm run dev

# 打包发布
npm run build
```

开发环境接口地址在 `.env.development` 中配置（默认 `http://localhost:8080`）。
