# ICEJZ UI 规范（简版）

## 品牌色

| Token | 色值 | 用途 |
|---|---|---|
| Primary | `#00A8E8` | 主按钮、菜单激活、链接 |
| Accent | `#3EC6FF` | 高亮、点缀 |
| Dark | `#141820` / `#1A2332` | 登录/侧栏暗色底 |
| Success | `#11C26D` | 成功 |
| Warning | `#EB6709` | 警告 |
| Danger | `#F56C6C` | 危险 |

## 布局

- 页面边距：`16px`
- 卡片圆角：`12px`
- 小圆角：`8px`
- 卡片阴影：`0 4px 20px rgba(20,24,32,.06)`
- 内容区背景：`#F4F7FB`

## 组件

- 主按钮使用 Primary，圆角 8px
- 表格行高适中，操作列使用 link 按钮
- 查询区与表格分区卡片化，间距 16px
- Logo 统一使用各端 `/logo.png` 或 `/images/logo.png`
