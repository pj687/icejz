# ICEJZ API 文档

低代码开发平台接口说明，按业务模块分组浏览与在线调试。

## 使用提示

- 左侧切换 **分组**，可分别查看系统、定时任务、监控、会员、物联网等接口
- 调试接口前请先在 Header 中设置 `Authorization`（登录后获取的 Token）
- 推荐使用「全局参数」保存常用调试参数，避免重复填写

## 模块说明

| 分组 | 说明 |
| --- | --- |
| 系统接口 | 认证、用户、权限、消息、参数与配置等 |
| 定时任务 | Quartz 调度与执行日志 |
| 系统监控 | 服务、缓存、在线用户 |
| 会员接口 | 会员相关能力 |
| 物联网 | 设备接入、事件与服务日志 |
